Run it yourself

  1. Install uv and clone the repo, e.g. to C:\Users\knigh\Documents\GitHub\georescue.
  2. In that folder: uv sync --extra verify, then uv run georescue run -c configs/duval_fl_ci.yaml (fetches public COJ parcels; it also builds out/georescue.duckdb) or, if you already have out/latest, just uv run georescue load-db.
  3. Add the server to Claude Desktop (Settings → Developer → Edit Config, claude_desktop_config.json):
    {
 "mcpServers": {
  "georescue": {
   "command": "uv",
   "args": [
    "run",
    "--directory",
    "C:\\Users\\knigh\\Documents\\GitHub\\georescue",
    "--extra",
    "verify",
    "georescue-mcp"
   ],
   "env": {
    "PYTHONPATH": "C:\\Users\\knigh\\Documents\\GitHub\\georescue"
   }
  }
 }
}
  4. or to Cursor (.cursor/mcp.json in the project, or Settings → MCP):
    {
 "mcpServers": {
  "georescue": {
   "command": "uv",
   "args": [
    "run",
    "--directory",
    "C:\\Users\\knigh\\Documents\\GitHub\\georescue",
    "--extra",
    "verify",
    "georescue-mcp"
   ],
   "env": {
    "PYTHONPATH": "C:\\Users\\knigh\\Documents\\GitHub\\georescue"
   }
  }
 }
}
  5. Restart the app and ask e.g. “Why is parcel 001542 0010 flagged?” or “What does sliver_polygon mean?”. Calls are logged to logs/mcp.log.

The store is read-only (SELECT-only guard, row cap, timeout) and owner names are redacted by default. repair_dataset only writes a repaired copy into a new folder. Results are test results, not surveys or legal advice. MCP server pattern adapted from the author's census-pipeline (MIT).

Data: City of Jacksonville / Duval Property Appraiser parcels (maps.coj.net CityBiz/Parcels); Duval Property Appraiser (paopropertysearch.coj.net); Duval Clerk of Courts Official Records (or.duvalclerk.com). Basemap © CARTO © OpenStreetMap contributors. Map library: MapLibre GL JS (BSD-3-Clause). Deed outlines are COGO traverses best-fit to GIS, not surveys; all fixes except invalid-geometry repair are proposals for review.
